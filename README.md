# 🐼 CSV Analyst - CSV 数据分析助手

基于 **Pandas + LLM** 的智能 CSV 数据分析工具，支持自然语言对话式数据分析和可视化。

## 🚀 快速开始

### 1. 安装依赖

```bash
# 克隆或下载项目后，进入项目目录
cd csv-analyst

# 同步依赖（使用 uv）
uv sync
```

### 2. 配置 API Key

创建 `.env` 文件并配置你的 API Key：

```bash
# 复制示例配置
cp .env.example .env

# 编辑 .env 文件，填入你的 API Key
# 支持 OpenAI 或阿里云 DashScope 等兼容 API
```

### 3. 启动应用

#### 🌟 方式一: Web 界面（推荐）

```bash
uv run csv-analyst
```

然后在浏览器中打开 `http://localhost:8501`

#### 📝 方式二: 命令行 Demo

```bash
# 快速演示
uv run csv-demo-quick

# 基础查询
uv run csv-demo-basic

# 多表关联
uv run csv-demo-multi

# 数据可视化
uv run csv-demo-viz
```

## 💬 使用示例

### Web 界面使用

1. 上传你的 CSV 文件（或点击"加载示例数据"）
2. 在聊天框中输入问题，例如：
   - "哪个地区的平均收入最高？"
   - "画一个收入分布的饼图"
   - "找出工资最高的3名员工"
   - "计算每个部门的平均薪资"

### 支持的查询类型

#### 📈 数据分析
```
"平均收入是多少？"
"哪个国家的员工数最多？"
"按地区统计总收入"
"计算收入和员工数的相关性"
```

#### 📊 数据可视化
```
"画一个收入分布的直方图"
"用饼图展示各地区收入占比"
"绘制收入和员工数的散点图"
"制作各部门薪资对比的条形图"
```

#### 🔗 多表关联（上传多个 CSV 时）
```
"谁的工资最高？"
"按部门统计平均薪资"
"列出 IT 部门的所有员工及其薪资"
"计算每个员工的总薪酬（工资+奖金）"
```
